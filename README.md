# ABC AUTO — exam-4

React + JSX, Vite, Tailwind CSS 4, MUI, React Router и Swiper.

## Запуск

```sh
npm install
npm run dev
```

`npm run build` — production-сборка. `npm run preview` — просмотр сборки.
Локальный API заявок работает и в dev, и в preview.

## Структура

- `src/pages/` — страницы и варианты страниц из макетов.
- `src/components/` — общие блоки, карточки, фильтры, формы и диалоги.
- `src/context/Store.jsx` — избранное, сравнение и управление диалогами.
- `src/data/cars.json` — исходные числовые данные новых автомобилей.
- `src/data/content.js` — отдельные предложения б/у и такси, программы и статьи.
- `src/assets/` — оригинальные отдельные изображения из папки пользователя.
- `server/applications.js` — локальный JSON API.
- `server/data/applications.json` — заявки, создаётся после первой отправки.

## Поведение

- Избранное и сравнение пусты при первом посещении; счётчики показывают действительный размер списков.
- Списки сохраняются в localStorage; данные разных категорий разделены вкладками.
- Фильтры применяются к данным каталога; количество результатов вычисляется.
- Каталог запоминает параметры фильтрации в URL.
- Сравнение показывает характеристики выбранных машин и умеет скрывать одинаковые строки.
- Кредитный калькулятор пересчитывает аннуитетный платёж при изменении машины, срока и взноса.
- Формы валидируют телефон и сохраняют заявку через API; успех показывается только после ответа 201.
- Заявки сохраняются локально и не отправляются реальному дилеру или банку.
- Комментарии и реакции сохраняются в текущем браузере.
- Фото и карточки используют Swiper. Изображения импортируются из assets, без CSS background-image и без скриншотов целых страниц.
- См. ROUTES.md для соответствия страницам макета.

## Данные и ограничения

Учебные цены, характеристики, комплектации, отзывы и рейтинги не являются актуальным предложением дилера.
Для демо-форм используйте тестовые контакты.
Исходные макеты содержат повторяющиеся изображения машин; заменены отдельными фотографиями соответствующих моделей из предоставленных assets.
Для отсутствующих в локальных данных марок и классов показаны честные пустые состояния.
Оригинальные видео к картинкам отзывов и «О компании» не приложены. Их нельзя восстановить из JPG; ссылки на точные ролики нужно указать отдельно.
Видеодиалог поддерживает YouTube videoId и не подставляет посторонний ролик.
Идентификаторы оригинальных YouTube-роликов добавляются в `src/data/videos.json`: `about` — ролик о компании, `reviews` — массив роликов по порядку карточек. Например, для ссылки `https://www.youtube.com/watch?v=VIDEO_ID` укажите только `VIDEO_ID`.
JSON API предназначен для локального запуска учебного проекта. Для публикации нужен сервер, который реализует тот же POST /api/applications.
